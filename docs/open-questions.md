# שאלות פתוחות

## נשלח לאורנית והועבר למור

1. **מחירים:** בקובץ אין עמודת מחיר. יש קובץ מחירים נפרד?
   - **עד התשובה:** מחיר המחשה קבוע לכל מק"ט, בטווח של תת-הקטגוריה, ומסומן בממשק (החלטה 6).
   - **התשובה של מור, אחרי מועד ההגשה:** לא מציגים שדה בלי ערך. מחירי ההמחשה הוסרו מהתצוגה (החלטה 25).
2. **גידול הקטלוג, עדיין ממתין לתשובה:** צריך להביא בחשבון ייבוא חוזר או עשרות אלפי מוצרים?
   - **בינתיים:** Seeder עם upsert לפי מק"ט (החלטה 7). `catalog:embed` מחשב רק מוצרים שהשתנו, וההשוואה נעשית בזיכרון (החלטה 5).
   - **אם התשובה היא כן:** פקודת ייבוא מתוזמנת ואינדקס וקטורי ייעודי.

| עימוד: "טען עוד" או מספרי עמודים | "הצגת מוצרים נוספים" (החלטה 18) |

| תמחור Laravel Cloud | Starter: החודש הראשון חינם, וכלול קרדיט של 5 דולר בחודש |
| מודל הווקטורים | `text-embedding-3-large`, אחרי ניסוי הוגן (החלטה 16) |

## פתוח לשיפור (לא חוסם הגשה)

- **כוונה שדורשת ידע עולם:** "שערות כלב מהספה" מעלה מברשת ושוטף שטיחים, אבל השואבים רחוקים (מקום 16). "מתנה לאמא טריה" לא מעלה מוצרים לתינוק. הפתרון המוצע הוא ניסוח מחדש במודל שפה, רק לשאילתות ארוכות, עם מטמון וגיבוי. הוחלט להשאיר ולתעד (החלטה 21).
- **מצב "מילות מפתח בלבד"** (רעיון של אמיר): מתג בממשק לחיפוש מדויק של המילים במסד, בלי ערוץ המשמעות. המנוע כבר תומך בזה.
