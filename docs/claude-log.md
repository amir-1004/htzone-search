### הצעה ששיניתי: פקודת ייבוא במקום Seeder

- **מה הוצע:** Claude המליץ על פקודת artisan ייעודית לייבוא, כי אפשר להריץ אותה שוב בפרודקשן.
- **מה החלטתי:** נשארתי עם Seeder, כי הוא מוכר ופשוט יותר להסביר. הוספתי upsert לפי מזהה, כדי שהרצה חוזרת לא תשכפל שורות. אם מור תגיד שהקטלוג יתעדכן, אעבור לפקודה.

### הצעות של Gemini שנדחו אחרי בדיקה עם Claude

| מה הוצע | מה בדקנו | החלטה |
|---|---|---|
| HTTP `SEARCH` לנקודת הקצה, עם ציטוט RFC 8141 | RFC 8141 עוסק ב-URN. הטיוטה הרלוונטית נקראת `QUERY` ועדיין לא תקן | GET רגיל (החלטה 8) |
| Vercel + Vercel Postgres | Vercel מריץ PHP רק דרך runtime של הקהילה, וגם העדפתי MySQL | Laravel Cloud + MySQL (החלטה 3) |
| "לנקות" קלט מפני XSS | העיקרון הנכון הוא קידוד פלט. Blade עושה את זה כברירת מחדל | טסט שמוודא שהסקריפט מוצג כטקסט |
| המלצות על Claude 3.5 / 3.7 | מודלים מדורות קודמים | עבודה עם Opus 5.5 לתכנון |
